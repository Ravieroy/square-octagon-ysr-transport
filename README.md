## Code for "Interference-controlled magnetic bound states and subgap transport in a Square--octagon superconductor"

This repository contains the code used for the research and the plots behind the paper currently in preprint, Ravi Kiran, *Interference-controlled magnetic bound states and subgap transport in a Square--octagon superconductor*, [arXiv:2609.07546](https://arxiv.org/abs/2609.07546)

A mildly pedagogical set of notebooks are added in the `tutorials` directory where I have tried to explain and contain certain parts of the programs for easy understanding.
