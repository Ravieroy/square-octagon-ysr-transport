# Changelog

## [v0.1.0] - 14/09/2026

### Added
- Initial public version of the repository.
- Square-octagon tight-binding and superconducting BdG model.
- Single-site magnetic impurity calculations using KWANT python package.
- Magnetic-adatom models for top, square-hollow, and octagon-hollow adsorption geometries.
- Adsorption-channel and flat-band overlap calculations.
- Magnetic bound-state calculations.
- Material-motivated three-hopping square--octagon model.
- Kwant-based normal--superconductor--normal transport calculations.
- Simple tutorial notebooks for understanding the core functions.
